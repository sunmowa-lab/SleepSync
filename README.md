

라즈베리 파이 연결 방법

1. 핸드폰 핫스팟을 킨다.
2. 이름을 SleepSync 로 설정 하고 비밀번호는 12345678로 설정한다 밴드는 2.4및5g로 설정 하고
   보안을 wpa2/wpa3-personal로 설정 한다
   
4. 컴퓨터에 Tailscale를 설치 한다. 개인 계정으로 로그인 하고
   https://login.tailscale.com/uinv/iCeEYKLiA611GBrvpbuAX11 이 url에 들어가서 초대를 수략 한다.

4.Windows PowerShell에 ssh pi@100.121.109.103를 입력 한다  
  비밀번호는 12345678 
  성공하면 pi@Sleepsync:~ $ 바귄다.

5. 파이 성능이 생각 보다 많이 안좋아서 계발 툴로 접근은 불가능 하고
   컴퓨터에 WinSCP를 설치해서 파일을 직접 옴겨 가면서 계발을 해야 한다.

이 방법은 서로 같은 와이 파이가 아니라도 파이에 접속이 가능 하다. 
핫스팟을 하는 이유는 파이가 인터넷이 되겠금 하기 위해서이다. 
파이에 저장 시켜 놓은 와이 파이가 SleepSync 이거 이기에 파이 환경이 바뀌면 현제 이 와이 파이 만 인식 한다. 
파이에 와이 파이를 추가 해도 좋다.
파이가 인터넷에만 연결 되어 있으면 어디 어디서든 파이에 접근이 가능하다

파이에서 자동으로 서비스 실행 중이라 컴퓨터에서 app.py를 실행 시키지 않기를 권고 한다. 
수정한 코드 파일을  WinSCP을 통해 파이에 넣으면 파이가 자동 실행 시키도록 해놨다.
